# 🌾 AgriSense — Smart Crop Disease Detection

AI-powered crop disease detection and field monitoring web app built with React + Node.js.

## Features
- 🔬 Crop disease detection from leaf photos
- 📊 Farm dashboard with alerts and weather
- 📡 Field monitor with sensor data
- 🤖 AI chat assistant for farming advice

## Tech Stack
- Frontend: React 18 + Vite
- Backend: Node.js + Express
- AI: Local disease detection database

## Setup & Run

### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev

Open http://localhost:3000
